# Мини-модель угроз ML-проекта

## 1. Описание защищаемой системы

Разрабатываемая система предназначена для обнаружения
prompt injection-атак во входных запросах к большим
языковым моделям.

Разработка осуществляется в виртуальной машине
Ubuntu 24.04 LTS с использованием Python, Git,
Docker и JupyterLab.

Основные защищаемые активы:
- Linux-сервер и SSH-доступ;
- исходный датасет;
- Python-зависимости;
- Git-репозиторий;
- разрабатываемая ML-модель;
- среда выполнения JupyterLab.

## 3. Анализ реализованных мер защиты

### Защита SSH

Для удаленного доступа настроена аутентификация
по SSH-ключу ED25519.

Вход пользователя root запрещен.
Парольная аутентификация отключена.

Firewall UFW ограничивает количество повторных
SSH-подключений и запрещает остальные входящие
соединения по умолчанию.

### Защита датасета

Для файлов train.csv, validation.csv и test.csv
вычислены контрольные суммы SHA256.

Эталонные значения сохранены в файле
security/datasets.sha256.

Проверка целостности всех трех файлов завершилась
успешно.

Контрольные суммы позволяют обнаружить изменения
относительно эталона, но не подтверждают
достоверность первоначального источника.

### Предотвращение утечек данных

В обучающей выборке обнаружены 37 полных дубликатов
и один текст с противоречивыми метками.

Между Train и Validation выявлено 4 совпадающих
текста, между Validation и Test — 116.

На следующих этапах необходимо устранить пересечения
между выборками и противоречивую разметку.

### Защита Python-окружения

Создано изолированное виртуальное окружение .venv.

Версии библиотек фиксируются в requirements.txt.

Проверка pip-audit не выявила известных
уязвимостей на момент выполнения лабораторной.

### Защита Git-репозитория

Файл .gitignore исключает виртуальное окружение,
секреты, датасеты и обученные модели.

Дополнительно рекомендуется использовать
автоматическое сканирование репозитория
на наличие секретов.

### Защита ML-модели

В следующих лабораторных работах предлагается
проводить тестирование устойчивости классификатора
к модифицированным prompt injection-запросам.

Планируется оценивать долю пропущенных атак,
ложноположительные срабатывания и устойчивость
модели к изменению текста.
